# Screenshots

The application's screens, for the shop pages and the documentation, taken
from djmanzo itself (§131). Being taken; the list below fills as they land.

## How the files are named

`<screen>--<theme>[--<skin>][--<state>].png`

- **screen**: what is shown (`cockpit`, `mixer`, `stems`, `karaoke-singers`, …)
- **theme**: the theme package it is drawn in
- **skin**: §129's artwork layer, when one is on
- **state**: what is happening (`playing`, `mixing`, `peak`, `empty`, …)
