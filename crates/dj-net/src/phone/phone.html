Android: Settings → Security → Encryption & credentials → Install a certificate → CA certificate, then choose djmanzo.crt. The names differ a little between phones.

iPhone: download it in Safari, then Settings → General → VPN & Device Management → install the djmanzo profile; then Settings → General → About → Certificate Trust Settings → turn djmanzo on.
