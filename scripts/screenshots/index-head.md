# Screenshots

djmanzo's screens in its themes, skins and states, for the shop and the
documentation (§131). Every picture is the real application, running, with
two records playing from a demo collection made for the purpose (original
music synthesised by `scripts/screenshots/make_music.py`, so nothing in a
picture is anyone else's work). 1600 × 900 pixels, PNG.

**Made by `scripts/screenshots/`** (see its README), so they can be made again
after the interface changes. One thing is removed from every picture: the
"UI n fps" warning djmanzo shows when it draws without a GPU, as it does where
these were taken. It never appears on a machine with graphics acceleration.
The top bar's "Null output (no hardware)" is left in: it is true where they
were taken, and a real sound card's name stands there otherwise.

## Names

`<screen>--<theme>[--<skin>].png`: what is on screen, then the theme it is
drawn in, then the skin worn over the theme, if any.
